# Python OSINT-CLI tool

** Disclaimer - project still in development for cloud research identification ** 

Welcome to my Python based reconnaissance tool for gathering publicly available information about their domains and network infrastructure.

Current functionality:
- DNS reconnaissance
- HTTP reconnaissance
- IP address and network information
- ASN ID
- Organisation and country information

Currently working on:
- ASN -to- cloud provider database
- cloud provider identification
- Additional useful features

** AI assisted research was used to support in IP intelligence, identify open source tools and compile publicly available ASN identifiers associated with cloud service providers **
